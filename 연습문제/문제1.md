## 연습문제1

### ✅ **요구 사항**
1. **홈 디렉토리 안에 `my-service`라는 이름의 프로젝트 디렉토리를 만들고, 다음과 같은 초기 구조를 만들어라.**

```text
my-service/
├── backend/
│   └── app.py
├── frontend/
│   └── index.html
└── README.md
└── test_config.py
└── old_index.html
```

```text
# 정답 
mkdir my-service

cd my-service
mkdir backend
mkdir frontend
touch README.md
touch test_config.py
touch old_index.html

```


2. **초기 파일 구조를 변경하라는 지시를 받았다. 팀장님의 지시에 맞게 파일을 적절한 위치로 복사하거나 이동하여 정리해라.** <br>
    - `test_config.py`를 `my-service/backend/`로 이동해라.<br>
    - `frontend/index.html`은 필요없는 파일이므로 삭제해라.<br>
    - `old_index.html` 파일을 `my-service/frontend/`로 복사해라. <br>
    복사할 때 파일명을 `index.html`로 바꾸면서 복사해라.<br>
    - `README.md`의 파일명을 `readme.md`로 변경해라.<br>
    
```sh
#test_config.py파일 이동
cd my-service
mv test_config.py ./backend
# index.html 파일 삭제
cd frontend
rm -rf index.html
# old_index.html을 frontend로 복사 + index.html로 이름변경
cd ..
cp old_index.html ./frontend/index.html

mv README.md readme.md


```

3. **환경 변수 파일(`.env`)을 `my-service/`에 만들어라.**
```text
touch .env
```
